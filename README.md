
  # Trivio

  This is a code bundle for Trivio. The original project is available at https://www.figma.com/design/gKd2AGl6Xi4P1bZcqgDi7R/Trivio.

  ## Running the code

  Run `npm install -g pnpm@9`
  Run `pnpm install` to install the dependencies.

  Run `pnpm dev` to start the development server.
