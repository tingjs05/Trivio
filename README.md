**Trivio** is an interactive classroom engagement platform designed to help students stay focused and actively participate during lectures. By connecting directly to a professor's presentation slides, Trivio transforms passive learning into an engaging, reward-driven experience.

## Mission

Trivio aims to solve one of the biggest challenges in modern education: maintaining student attention during lectures. By combining real-time interaction, gamification, and meaningful rewards, Trivio helps students stay engaged, learn more effectively, and transform classroom participation into a fun and rewarding experience.

## How It Works

During a lecture, professors can send out real-time **Pulses**—short attention checks that appear on students' devices at random intervals. These Pulses may require students to:

* Answer a question related to the current lecture content
* Enter a keyword mentioned by the professor
* Identify information displayed on the current slide
* Complete quick comprehension checks
* Respond to polls or mini-quizzes

Because Pulses can occur at any time, students are encouraged to remain attentive throughout the lesson to avoid missing important information.

## Gamified Learning Experience

Each correctly completed Pulse rewards students with **Points**. The more engaged students are during class, the more points they earn.

Points can be redeemed through the Trivio Marketplace for various rewards, such as:

* University merchandise
* Cafeteria vouchers
* Event tickets
* Exclusive campus perks
* Assignment Extensions 

_(Rewards are subject to change depending on the instructors or institutions using Trivio)_

## How to run?

Run `npm install -g pnpm@9`

Run `pnpm install` to install the dependencies.

Run `pnpm dev` to start the development server.
